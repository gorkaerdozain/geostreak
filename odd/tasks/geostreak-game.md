# geostreak-game — endless country-guessing globe

Objective: a globe game where you guess random countries one after another, with distance feedback, a capped number of attempts and a running streak.
Branch: `main`. Delivery strategy: `ask-on-risk`. Test runner: `bun run test` (Vitest via Vite+).

## Specs

- S1 Endless mode: "no sea como los tipicos de 1 al dia, sino una ristra aleatoria para q puedas jugar indefinidamente". Countries come from a shuffled deck; no country repeats until the deck is exhausted.
- S2 Attempts: "poner un tope de intentos". Default 10 attempts per country; on the last failed attempt the country is revealed and the streak resets.
- S3 Distance: "entre fronteras el calculo de distancia". Distance is the shortest border-to-border distance in km; neighbouring countries are 0 km.
- S4 Feedback: "te tiene q salir un punto en el pais o colorearse en base a la distancia del real a adivinar, con la distancia en un hover card, popover, tooltip siempre visible".
- S5 Country info: "al clicar los paises q vas eligiendo ... te sale un dialog, popover, drawer... con mas info del pais".
- S6 Search: "se busca paises con un inputgroup, autocomplete o combobox, q te vaya autocompletando y tenga todos los paises, a poder ser con su bandera".
- S7 Animations with `motion` where they add value.
- S8 Globe: a dotted globe built with cobe (https://cobe.vercel.app), light theme by default; drag, zoom, auto-rotate, a smooth flight to each guessed country and an entry animation.
- S9 Ranking: a dialog with stats, the best streaks and the latest rounds.
- S10 Round feedback: "algo mas llamativo en medio de la pantalla, un confeti... algo cuando ganas y cuando pierdes".
- S11 Settings: theme (light, dark, system), always-visible distance labels, auto-rotate; ⌘K / Ctrl+K focuses the search.
- Assumption: search matches English and Spanish names, accent-insensitive.

## Log

- L1 User request: "quiero un juego de adivinar paises con un globo terraqueo, partida infinita aleatoria, tope de intentos, distancia entre fronteras, buscador con bandera y detalle del pais al clicar".
- L2 Data: Natural Earth 110m geometries joined with `world-countries` metadata, generated by `scripts/build-countries.ts` into `src/data/countries.json` (bundled, no runtime API).
- L3 Decision: border distance = minimum haversine distance between polygon vertices, 0 km for countries listed as land neighbours.
- L4 Globe: cobe 2 draws its own world map as a spherical Fibonacci lattice with limb fading. Guessed countries become cobe markers on the same lattice points (`src/game/dots.ts` mirrors the shader), and labels use cobe's CSS anchors (`--cobe-visible-*` drives opacity and blur). cobe has no render loop or controls: the component drives `update()` from `requestAnimationFrame` with time-based rotation, drag, wheel/pinch zoom, a 900 ms focus flight and an entry animation.
- L5 Extra facts: REST Countries v3.1 is retired and v5 needs a key, so the drawer reads Wikidata SPARQL + the Wikipedia REST summary (no key, CORS enabled), with a skeleton while loading.
- L6 Ranking: a streak enters the top list when it ends (a lost round); the in-progress streak and the last 20 rounds are persisted so the dialog is never empty after playing.
