# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

`ccdemo` is a single-page React app scaffolded with the shadcn Vite template (base-ui primitives, `base-rhea` style, Hugeicons). There is no backend.

## Commands

Package manager is **bun**. The toolchain is **Vite+** (`vp`), which bundles Vite, Vitest, Oxlint and Oxfmt.

- `bun run dev`: dev server (`vp dev`)
- `bun run build`: typecheck (`tsc -b`) and production build (`vp build`)
- `bun run test`: unit tests (`vp test`, Vitest). Single file: `bunx vp test src/path/file.test.ts`
- `bun run check`: format + lint + type-aware checks (`vp check`); `bunx vp check --fix` autofixes
- `bun run typecheck`: `tsc -b` (TypeScript 7, native compiler)

## Conventions

- Import from `vite-plus` / `vite-plus/test` instead of `vite` / `vitest` (enforced by the `vite-plus/prefer-vite-plus-imports` lint rule).
- Path alias `@/*` → `src/*`.
- UI primitives live in `src/components/ui` and are generated by the shadcn CLI (`bunx --bun shadcn@latest add <component>`). Do not edit them by hand unless necessary; they are excluded from lint.
- Tailwind CSS v4: theme tokens are CSS variables in `src/index.css`; there is no `tailwind.config`.
- Formatting: no semicolons, double quotes, trailing commas (es5), 2 spaces. Run `bunx vp check --fix` before committing.
- Configuration for lint, fmt and test lives in `vite.config.ts`.
